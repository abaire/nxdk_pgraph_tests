Remarks
Cubemap Renders two angles of a cube utilizing a cubemap texture.
CubemapZeroVector Renders screen-space quads point sampling a cubemap with a constant texture coordinate per quad. Every texel has a unique color that encodes its face and position: R = x * 4 + 2, G = y * 4 + 2, B = face * 40 + 20, with faces ordered +X, -X, +Y, -Y, +Z, -Z. The exception is texel (0, 0) of the +X face, which is pure magenta. The large quads use zero length directions: (0, 0, 0, 1), (0, 0, 0, 0), and (-0, -0, -0, 1). The small quads below them are a self check of the texel encoding, sampling the +/-X, +/-Y, and +/-Z axis directions in pairs.

On hardware, all three zero length directions sample texel (0, 0) of the +X face. The self check quads each sample texel (32, 32) of the matching face.

Remarks
CubemapZeroVectorMipmap_Point Renders screen-space quads sampling a 64x64 A8B8G8R8 cubemap with 4 mipmap levels (64, 32, 16, 8) in stage 3 using PS_TEXTUREMODES_CUBEMAP. The filter is MIN_BOX_NEARESTLOD with MAG_BOX_LOD0, and the U, V, and P wrap modes are WRAP_CLAMP_TO_EDGE. Colors are given as ARGB. On the +X face, every texel of level 0, 1, 2, 3 is 0xFF0000A0, 0xFF00A000, 0xFFA00000, 0xFFA0A0A0 respectively, except for: texel (0, 0), which is 0xFFFF00FF, 0xFF00FFFF, 0xFFFFFF00, 0xFFFFFFFF on level 0, 1, 2, 3; texel (1, 0), which is 0xFFFF8000; texel (0, 1), which is 0xFF8000FF; texel (1, 1), which is 0xFF00FF80; the last column, which is 0xFF000000; the last row, which is 0xFF808000; and the last texel of the last row, which is 0xFF008080. Every texel of every level of the other faces is a single color per face: -X 0xFF603030, +Y 0xFFFF80C0, -Y 0xFF306030, +Z 0xFF80C0FF, -Z 0xFF303060.

Each column of quads uses a different NV097_SET_TEXTURE_CONTROL0 MIN_LOD_CLAMP raw value (n), MAX_LOD_CLAMP raw value (x), and NV097_SET_TEXTURE_FILTER MIPMAP_LOD_BIAS raw value (b). Unless listed, n is 0, x is 0xFFF, and b is

  1. Left to right: "none" (defaults), n=0x001, n=0x002, n=0x100, n=0x200, b=0x100, b=0x200, b=0xFFF, x=0x000, x=0x100, x=0x200. Rows, top to bottom: "0" quads have the texture coordinate (0, 0, 0, 1) at every vertex. "C" quads have the texture coordinate (1, 0, 0, 1) at every vertex, the center of the +X face. "T" quads have the texture coordinate (1, 63/64, 63/64, 1) at every vertex, which is s = t = 1/128 on the +X face, inside texel (0, 0) of every level. "G" quads are 44x44 pixels with texture coordinates from (1, 0.6875, 0.6875, 1) at the top left to (1, -0.6875, -0.6875, 1) at the bottom right, covering 44x44 texels of level 0 in the center of the +X face.
Remarks
CubemapZeroVectorMipmap_Linear The same as CubemapZeroVectorMipmap_Point, except the filter is MIN_TENT_TENT_LOD with MAG_TENT_LOD0.
CubemapZeroVectorMipmap_LinearWrap The same as CubemapZeroVectorMipmap_Linear, except the U, V, and P wrap modes are WRAP_REPEAT.
CubemapZeroVectorFilters Renders 44x44 screen-space quads sampling the 4 level mipmapped cubemap described in CubemapZeroVectorMipmap_Point in stage 3 using PS_TEXTUREMODES_CUBEMAP. Every quad has the texture coordinate (0, 0, 0, 1) at every vertex. For every quad the U, V, and P wrap modes are WRAP_REPEAT, the MIN_LOD_CLAMP raw value is 0, the MAX_LOD_CLAMP raw value is 0xFFF, the MIPMAP_LOD_BIAS is 0, the convolution kernel is K_QUINCUNX, anisotropy is 1, and the border source is NV097_SET_TEXTURE_BORDER_COLOR with the value 0xFFFF0000. The top row of quads uses MAG_BOX_LOD0 ("magB") and the bottom row uses MAG_TENT_LOD0 ("magT"). Left to right, the min filters are MIN_BOX_LOD0 ("B0"), MIN_TENT_LOD0 ("T0"), MIN_BOX_NEARESTLOD ("BN"), MIN_TENT_NEARESTLOD ("TN"), MIN_BOX_TENT_LOD ("BT"), and MIN_TENT_TENT_LOD ("TT").

On hardware, both rows are identical, so only the min filter matters. MIN_BOX_LOD0 gives texel (0, 0) of level 0. MIN_TENT_LOD0 blends 1/4 each of texel (0, 0), the last texel of row 0, the last texel of column 0, and the last texel of level 0. MIN_BOX_NEARESTLOD and MIN_BOX_TENT_LOD give texel (0, 0) of level 3. MIN_TENT_NEARESTLOD and MIN_TENT_TENT_LOD blend the same four texels of level 3.

Remarks
CubemapZeroVectorConvolution Renders 44x44 screen-space quads sampling the 4 level mipmapped cubemap described in CubemapZeroVectorMipmap_Point in stage 3 using PS_TEXTUREMODES_CUBEMAP. Every quad has the texture coordinate (0, 0, 0, 1) at every vertex. For every quad the MIN_LOD_CLAMP raw value is 0, the MAX_LOD_CLAMP raw value is 0xFFF, the MIPMAP_LOD_BIAS is 0, anisotropy is 1, and the border source is NV097_SET_TEXTURE_BORDER_COLOR with the value 0xFFFF0000. Left to right, the columns use MIN_CONVOLUTION_2D_LOD0 with MAG_CONVOLUTION_2D_LOD0 and the K_QUINCUNX kernel ("CCQ"), MIN_CONVOLUTION_2D_LOD0 with MAG_CONVOLUTION_2D_LOD0 and the K_GAUSSIAN_3 kernel ("CCG"), MIN_CONVOLUTION_2D_LOD0 with MAG_BOX_LOD0 ("CB"), MIN_CONVOLUTION_2D_LOD0 with MAG_TENT_LOD0 ("CT"), MIN_BOX_NEARESTLOD with MAG_CONVOLUTION_2D_LOD0 ("BNC"), and MIN_TENT_TENT_LOD with MAG_CONVOLUTION_2D_LOD0 ("TTC"). The last four use the K_QUINCUNX kernel. The U, V, and P wrap modes of the top row ("WRAP") are WRAP_REPEAT and of the bottom row ("CLMP") are WRAP_CLAMP_TO_EDGE.

On hardware, only the min filter matters: "CB" and "CT" are identical to "CCQ", "BNC" samples texel (0, 0) of level 3, and "TTC" matches MIN_TENT_TENT_LOD in CubemapZeroVectorFilters with WRAP_REPEAT and gives texel (0, 0) of level 3 with WRAP_CLAMP_TO_EDGE. MIN_CONVOLUTION_2D_LOD0 filters level 0 around texel (0, 0), applying the wrap mode to texels outside the face. The K_GAUSSIAN_3 results match a 3x3 kernel centered on texel (0, 0) with weights 1/4 for the center, 1/8 for edges, and 1/16 for corners. The K_QUINCUNX results match 1/2 of texel (0, 0) plus 1/8 each of texels (-1, 0), (1, 0), (-1, 1), and (1, 1).

Remarks
CubemapZeroVectorAddressModes Renders 44x44 screen-space quads sampling the 4 level mipmapped cubemap described in CubemapZeroVectorMipmap_Point in stage 3 using PS_TEXTUREMODES_CUBEMAP. Every quad has the texture coordinate (0, 0, 0, 1) at every vertex. For every quad the P wrap mode is WRAP_CLAMP_TO_EDGE, the MIN_LOD_CLAMP raw value is 0, the MAX_LOD_CLAMP raw value is 0xFFF, the MIPMAP_LOD_BIAS is 0, the convolution kernel is K_QUINCUNX, anisotropy is 1, and the border source is NV097_SET_TEXTURE_BORDER_COLOR with the value 0xFFFF0000. The left block of quads uses MIN_TENT_TENT_LOD with MAG_TENT_LOD0. Left to right, its columns use the address mode WRAP_REPEAT ("WRAP"), WRAP_MIRROR ("MIRR"), WRAP_CLAMP_TO_EDGE ("CLMP"), WRAP_BORDER ("BRDR"), and WRAP_CLAMP_TO_EDGE_OGL ("OGL"). The right block of quads uses MIN_BOX_NEARESTLOD with MAG_BOX_LOD0. Left to right, its columns use WRAP_MIRROR ("MIRR"), WRAP_BORDER ("BRDR"), and WRAP_CLAMP_TO_EDGE_OGL ("OGL"). Top to bottom, the rows of both blocks set U to the column's address mode with V WRAP_CLAMP_TO_EDGE ("U=m"), U WRAP_CLAMP_TO_EDGE with V set to the column's address mode ("V=m"), and both U and V set to the column's address mode ("UV=m").

On hardware, every quad samples level 3. With MIN_TENT_TENT_LOD, an axis set to WRAP_REPEAT blends texel (0, 0) 50/50 with the last texel of that row or column, and an axis set to WRAP_BORDER or WRAP_CLAMP_TO_EDGE_OGL blends it 50/50 with the border color. When both axes do so, the four texels in the 2x2 footprint are blended 1/4 each. WRAP_MIRROR and WRAP_CLAMP_TO_EDGE give texel (0, 0). With MIN_BOX_NEARESTLOD every address mode gives texel (0, 0).

DotSTRCubeZeroVector Renders screen-space quads using PS_TEXTUREMODES_DOT_STR_CUBE on stage 3 (stage 0 is 2D projective, stages 1 and 2 are PS_TEXTUREMODES_DOT_PRODUCT), point sampling a cubemap in stage 3. The cubemap texel encoding is the same as in CubemapZeroVector. NV097_SET_DOT_RGBMAPPING is set to dotmap_zero_to_one for all stages. Stage 0 is a 4x4 texture of constant color 0xFFFFFFFF, so the dot products are dot(Ti.xyz, (1, 1, 1)). Each large quad has constant texture coordinates and the xyz components of stages 1-3 are all 0, so (dot1, dot2, dot3) = (0, 0, 0). The w components of stages 1-3 differ per quad: (0, 0, 0), (1, 1, 1), and (-1, 0.5, 2). NV097_SET_EYE_VECTOR is (0, 0, 0). The small quads below them are a self check of the texel encoding. Each sets a single xyz component of one stage to +/-1 and the rest to 0 so that (dot1, dot2, dot3) is +/-X, +/-Y, or +/-Z, in pairs.
DotReflectDiffuseZeroVector Renders screen-space quads using PS_TEXTUREMODES_DOT_RFLCT_DIFF on stage 2 (stage 0 is 2D projective, stage 1 is PS_TEXTUREMODES_DOT_PRODUCT, stage 3 is PS_TEXTUREMODES_DOT_RFLCT_SPEC), point sampling a cubemap in stage 2 and outputting only stage 2. The cubemap texel encoding is the same as in CubemapZeroVector. The dot RGB mapping, stage 0 texture, large quad texture coordinates, w components, eye vector, and self check quads are the same as in DotSTRCubeZeroVector. The cube direction is the normal N = (dot1, dot2, dot3).
DotReflectSpecZeroVector Renders screen-space quads using PS_TEXTUREMODES_DOT_RFLCT_SPEC on stage 3 (stage 0 is 2D projective, stages 1 and 2 are PS_TEXTUREMODES_DOT_PRODUCT), point sampling a cubemap in stage 3. The cubemap texel encoding, dot RGB mapping, and stage 0 texture are the same as in DotSTRCubeZeroVector. The normal is N = (dot1, dot2, dot3) and the eye vector is E = (T1.w, T2.w, T3.w). The cube direction is R = 2 * N * dot(N, E) / dot(N, N) - E. NV097_SET_EYE_VECTOR is (0, 0, 0). The large quads, left to right, use N = (0, 0, 0) with E = (0, 0, 0), N = (0, 0, 0) with E = (1, 0, 0), N = (0, 0, 0) with E = (0, 0, 1), and N = (1, 1, 0) with E = (0, 1, 0), which reflects to (1, 0, 0). The small quads below them are a self check of the texel encoding. Each has N = +X, +Y, or +Z and E = +/-N so that R is +/-X, +/-Y, or +/-Z, in pairs.
DotReflectSpecConstZeroVector Renders screen-space quads using PS_TEXTUREMODES_DOT_RFLCT_SPEC_CONST on stage 3 (stage 0 is 2D projective, stages 1 and 2 are PS_TEXTUREMODES_DOT_PRODUCT), point sampling a cubemap in stage 3. The cubemap texel encoding, dot RGB mapping, stage 0 texture, and quad normals are the same as in DotReflectSpecZeroVector. The eye vector E is provided via NV097_SET_EYE_VECTOR, which is set before each quad, and the w components of stages 1-3 are 1. The large quads and self check quads use the same N and E as in DotReflectSpecZeroVector.
DotReflectDiffuse_-1to1 Renders two angles of a cube utilizing PS_TEXTUREMODES_DOT_RFLCT_DIFF pixel shading mode. The NV097_DOT_RGBMAPPING is set to dotmap_minus1_to_1.
DotReflectDiffuse_-1to1D3D Renders two angles of a cube utilizing PS_TEXTUREMODES_DOT_RFLCT_DIFF pixel shading mode. The NV097_DOT_RGBMAPPING is set to dotmap_minus1_to_1_d3d.
