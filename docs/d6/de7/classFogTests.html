Detailed Description

Tests behavior of NV2A fixed-function fog modes and generation modes.

Remarks
AFF-linear-planar Linear planar fog with fixed-function vertex processing. Four white triangles fade into reddish-purple fog as depth increases.
AFF-exp-planar Exponential planar fog with fixed-function vertex processing. Four white triangles fade exponentially into reddish-purple fog as depth increases.
AFF-exp2-planar Exponential squared planar fog with fixed-function vertex processing. Four white triangles fade into reddish-purple fog with quadratic depth falloff.
AFF-linear_abs-planar Linear absolute-value planar fog with fixed-function vertex processing.
AFF-exp_abs-planar Exponential absolute-value planar fog with fixed-function vertex processing.
AFF-exp2_abs-planar Exponential squared absolute-value planar fog with fixed-function vertex processing.
